# Dashboard Screenshots Folder

Place your 5 operator dashboard screenshots in this folder using these exact filenames:

1.  **Overview Page**: `overview.png`
2.  **Prediction Page**: `prediction.png`
3.  **Recommendations Page**: `recommendations.png`
4.  **Analytics Page**: `analytics.png`
5.  **Historical Cases Page**: `history.png`

Once placed, they will render automatically on the GitHub repository home landing page!
